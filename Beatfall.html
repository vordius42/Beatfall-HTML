Beatfall

Pilih lagu dari HP-mu, nadanya dibuat otomatis dari beat.

Mendukung MP3, WAV, OGG, M4A, dan FLAC (tergantung browser).

Pengaturan lanjutan
Tampilan saat main

Sensitivitas: makin tinggi, makin banyak beat terdeteksi (terkunci saat eksperimen note ikut kecepatan aktif). Kalibrasi: geser kanan jika ketukanmu sering terlambat, kiri jika terlalu cepat. Keyboard: D F J K.

Dasar

Pilih file musik, pilih tingkat kesulitan, lalu Mulai main. Ketuk lajur (atau tombol D F J K) saat note menyentuh garis. Note panjang harus ditahan sampai selesai.

Tingkat kesulitan

Mudah, Sedang, dan Sulit: makin tinggi makin padat. Multi-jari: boleh memakai lebih dari 2 jari.

Opsi note

Note panjang: note yang ditahan; muncul di lajur berbeda setiap kali nada lagu berubah. Berkelanjutan: nada panjang dalam lagu menjadi note panjang besar, dan note panjang lain bisa muncul di dalamnya. Panjang ganda: dua note panjang bersamaan dan note biasa diblokir; hanya bisa aktif jika Note panjang aktif, dan menggantikan Note ganda. Note ganda: dua note ketuk bersamaan.

Kecepatan

1x sampai 4x. Makin cepat, skor makin besar. Di atas 2.5x ada peringatan.

Pengaturan lanjutan

Jeda note panjang: jarak minimum antar note panjang. Sensitivitas beat: makin tinggi makin banyak beat terdeteksi (terkunci saat eksperimen kecepatan aktif). Kalibrasi: geser kanan jika ketukanmu sering terlambat, kiri jika terlalu cepat. Eksperimen note ikut kecepatan: jumlah note bertambah mengikuti kecepatan. Eksperimen sambung note panjang: dua atau tiga note panjang di lajur berbeda disambung jadi satu; geser jarimu ke lajur baru tanpa melepas (di keyboard, tekan tombol lajur baru). Perlu Note panjang aktif. Mode uji: game memainkan chart sendiri supaya kamu bisa melihat kemunculan note tanpa bermain; statistik chart tampil di kiri atas. Grafik: Otomatis, Tinggi, atau Rendah; pilih Rendah jika game terasa berat. Tampilan saat main: tampilkan FPS, akurasi, miss, kombo tertinggi, dan kombo saat ini.

Editor level

Buka Editor level setelah memilih musik. Game membaca BPM untuk memasang garis ketukan; geser layar untuk menggulir waktu, lalu pilih alat: Biasa (ketuk), Panjang (titik awal lalu akhir), Sambung (titik awal, titik pindah lajur, titik akhir, lalu Selesai), atau Hapus. Tombol Rekam memutar lagu dan mencatat permainanmu: ketuk jadi note biasa, tahan jadi note panjang, tahan dan geser jadi note sambung. Simpan menghasilkan file level (hanya nada), Simpan+musik menyertakan musiknya. Level tanpa musik hanya bisa dimainkan jika kamu memilih file musik dengan judul yang sesuai. Muat level untuk membuka file level.

Di bagian atas editor kamu bisa mengisi nama pembuat dan password edit (opsional). Level dengan password tidak bisa dibuka di editor tanpa password itu, tetapi ini hanya perlindungan di dalam game, bukan enkripsi file. Background level juga opsional dan dipakai saat bermain jika Background gameplay diatur ke Ikuti level kustom. Tombol Sembunyikan menu memperluas area chart; tombol Menu di pojok kanan atas memunculkannya kembali.

Tampilan dan background

Tombol Tampilan di menu mengatur skala UI, background menu utama (gambar, video yang dibisukan, atau GIF), dan background gameplay: Polos, Gambar, Ikuti level kustom, atau Spektrum. Spektrum punya pengaturan sensitivitas, jumlah bar (32–128), orientasi, posisi, dan warna (atau pelangi). Background disimpan di browser jika browser mengizinkan.

Deteksi nada

Slider Deteksi nada (0–200%) mengatur seberapa kuat game memakai perubahan nada untuk menaruh dan memindahkan note panjang. 0% = seperti sebelum fitur ini ada, 100% = normal, 200% = eksperimen. Hasilnya berbeda tiap lagu; coba ubah bersama sensitivitas beat.

Tombol Garis menampilkan garis interval berwarna sesuai pilihan 1/1 sampai 1/8 (merah = ketukan, biru = 1/2, ungu = 1/3 dan 1/6, kuning = 1/4, oranye = 1/8). Saat Uji main dijeda atau selesai, ada tombol Kembali ke editor.

Folder musik

Tombol Folder musik membuka daftar lagu dari folder pilihanmu, dengan judul, artis, dan album dari metadata, pencarian, dan pengurutan. Di browser yang mendukungnya, folder terakhir diingat; di browser lain (termasuk kebanyakan Android) kamu perlu memilih ulang folder tiap sesi.

Saat bermain

Tombol Jeda (atau Esc/P) membuka menu: Lanjutkan (hitung mundur 3 detik), Ulangi lagu, ganti grafik, atau Keluar. Game juga jeda otomatis jika kamu pindah aplikasi.
