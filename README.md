This is the HTML. You can download it and open it in your browser. It works on both mobile and desktop devices.

Since this game is fully done with AI, it may be extremely buggy.

You are free to fork/modify it in any way. Just... don't use it for commercial purposes, duh? Who would want an AI-generated game with microtransactions, anyway? I did this for fun.

Features:
- Automatic chart generation with customizable beat and pitch detection
- Swipe notes (similar to Colorful Stage)
- Level editor (yes), with password protection to prevent your chart from being edited without permission (it's still decryptable if you know how to edit the .JSON)
- Ability to read through your folder (it will take a while to load)
- Lightweight, less than 10 megabytes. Hell, it barely reaches 1!
- Customizable background
